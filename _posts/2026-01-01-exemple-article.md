## Introduction

Jekyll est un générateur de sites statiques simple, adapté aux blogs, aux sites personnels et aux projets. Voici comment créer votre propre blog avec Jekyll.

## Installation

Pour installer Jekyll, vous aurez besoin de Ruby et RubyGems. Ensuite, exécutez simplement :

```bash
gem install jekyll bundler
```

## Création d'un nouveau site

```bash
jekyll new mon-blog
cd mon-blog
```

## Structure des fichiers

La structure de base d'un site Jekyll ressemble à ceci :

- `_posts/` : Vos articles de blog
- `_layouts/` : Les modèles de mise en page
- `_includes/` : Fragments de code réutilisables
- `_config.yml` : Configuration du site

## Conclusion

Jekyll est un outil puissant pour créer des blogs statiques rapidement et efficacement.
