## Rappel

### Structure d'une lignes sur Canon X-07

Code d'une ligne basic

```
[adresse suivante] [numéro de ligne] [token REM] [contenu REM] [00]

[ptr ligne suivante] (2 octets)
[numéro de ligne]    (2 octets)
[token REM]          (1 octet)
[contenu REM]        (n octets)
[00]                 (fin de ligne)

```

```asm
                ORG 1F2C

1F2C : 16 00        LD   D,00h			; D=0 toujours
1F2E : 1E 00        LD   E,00h			; ici Poke de la valeur max <256 - 1F2F = 7983
1F30 : ED 5F        LD   A,R			; Lecture du nombre aléatoire <128 dans R
1F32 : 6F           LD   L,A			; sauvegarde dans L
1F33 : 3A 6A 1F     LD   A,(1F6Ah)		; lecture de la variable précédente
1F36 : AD           XOR  L				; calcul de la variable suivante
1F37 : 17           RLA					; Rotation gauche - A varie entre 0 et 254
1F38 : 6F           LD   L,A			; Sauvegarde dans L
1F39 : ED 5F        LD   A,R			; Nombre aléatoire
1F3B : AD           XOR  L				; Calcul de la variable suivante
1F3C : 32 6A 1F     LD   (1F6Ah),A		; Nouvelle variable en 1F6A
1F3F : CD 48 1F     CALL 1F48h			; Appel sous-routine
1F42 : 7C           LD   A,H			; Nombre aléatoire entre 0 et max-1
1F43 : 3C           INC  A				; Nombre aléatoire entre 0 et max
1F44 : 00           NOP					; R augmente d'1 cran
1F45 : C3 56 1F     JP   1F56h			; Saut à la fin
1F48 : 21 00 00     LD   HL,0000h		; Sous programme
1F4B : 29           ADD  HL,HL			; Décalage gauche de HL (HL = HL * 2)
1F4C : CB 27        SLA  A				; Décale A vers la gauche, Le bit sortant va dans Carry
1F4E : D2 52 1F     JP   NC,1F52h		; Si le bit extrait = 0 alors jump 1F52
1F51 : 19           ADD  HL,DE			; Si le bit extrait = 1 alors HL += DE
1F52 : C2 4B 1F     JP   NZ,1F4Bh		; Continue tant que A <> 0
1F55 : C9           RET					; retour
1F56 : 32 26 1F     LD   (1F26h),A		; Stocke A dans 1F26
1F59 : C9           RET					; retour au basic
```

1F6A contient un octet arbitraire. Semble assez dangereux de prendre au pif.

Le nombre d'octet se loge sans problème dans une ligne REM.

## Mise en pratique

### Refactorisation


```asm
; ============================================================
;  MODULE PRNG RELOGEABLE Z80 — VERSION FINALE
;  IX = base du module (auto-initialisé)
;  Variables à la fin : SEED, LASTA
; ============================================================

            ; --- auto-initialisation de IX ---
00  CD 03 00        CALL $+3
03  DD E1           POP IX              ; IX = adresse du module

            ; --- début de la routine principale ---
05  16 00           LD  D,00h           ; D = 0
07  DD 5E 01        LD  E,(IX+1)        ; E = paramètre poké (offset 1)

0A  ED 5F           LD  A,R             ; A = R
0C  6F              LD  L,A             ; L = R

0D  DD 7E 20        LD  A,(IX+SEED)     ; A = graine
10  AD              XOR L               ; mélange
11  17              RLA                 ; diffusion
12  6F              LD  L,A             ; L = mélange

13  ED 5F           LD  A,R             ; second mélange
15  AD              XOR L
16  DD 77 20        LD  (IX+SEED),A     ; mise à jour graine

19  CD 22 00        CALL ROUT2          ; appel routine secondaire

1C  7C              LD  A,H             ; résultat principal
1D  3C              INC A               ; +1
1E  C9              RET

; ============================================================
;  ROUT2 — routine bit-par-bit (équivalent de 1F48h)
; ============================================================

; ROUT2:
1F  21 00 00        LD  HL,0000h        ; HL = 0

22  29              ADD HL,HL           ; HL <<= 1
23  CB 27           SLA A               ; extrait bit dans Carry
25  30 03           JR  NC,NOADD        ; si 0 → pas d’ajout
27  19              ADD HL,DE           ; si 1 → HL += DE

; NOADD:
28  20 F8           JR  NZ,22h          ; boucle tant que A ≠ 0
2A  C9              RET

; ============================================================
;  STORE A (équivalent de 1F56h)
; ============================================================

; STORE:
2B  DD 77 21        LD (IX+LASTA),A     ; sauvegarde A
2E  C9              RET

; ============================================================
;  VARIABLES (juste après le code)
; ============================================================

; Offsets :
;   +20 = SEED
;   +21 = LASTA

20  00              SEED:  DEFB 0
21  00              LASTA: DEFB 0

```




Routine BASIC qui recherche une ligne et renvoie l'adresse mémoire (RALP).

- NL = Numéro de ligne recherchée
- AD = Adresse retour si trouvé sinon 0
- A = variable interne, parcours mémoire
- LN = variable interne pour la ligne scannée


```basic
60000 ' -----------------------------------------
60010 ' Recherche REM et retourne adresse dans AD
60020 ' -----------------------------------------
60030 A=PEEK(&H8000)+256*PEEK(&H8001):  ' A= debut code basic
60040 LN=PEEK(A+2)+256*PEEK(A+3):       ' LN= numero de ligne
60050 IF LN=NL THEN AD=A+5: GOTO 60090: ' ligne trouvee, on fixe AD avec l'adresse mémoire
60060 A=PEEK(A)+256*PEEK(A+1):          ' passe a la ligne suivante
60070 IF A<>0 THEN GOTO 60030:          ' continue si pas fin de code basic
60080 AD=0:                             ' Pas de ligne trouvee, alors mise a 0
60090 RETURN
```

On peut donc charger des variables avec une boucle (ex: S1, S2, etc...).

```basic

10 REM code LM
...
1000 '
1010 ' exemple
1020 '

...
```
