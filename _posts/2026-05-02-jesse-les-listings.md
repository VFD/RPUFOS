## Présentation

Jeux & Stratégie (NDR: Jesse pour les intimes) est une revue qui a été publié au 20ème siècle dans les années 1980s.

- Jeux & Stratégie (60 numéros) de janvier 1980 à Juillet/Août 1989
- Jeux & Stratégie Nouvelle formule

Avec la micro informatique, les premiers programmes sont apparus dans la revue.\
Depuis le no 01 au No 53.\
Incluant les calculatrices programmables.

Il existe un site d'[archivage des listings de revues](http://abandonlistings.free.fr/), mais pas de Jesse dedans.\
Sans compter que le site lui-même est probablement à l'abandon.

Ce projet à pour but de préserver les listings de Jesse.\
Généreux claviste, merci de vos contribution.

La revue est disponible sur [Abandonware Magazines](https://www.abandonware-magazines.org/).

## Le projet

Il nous faut les codes listings tel que donnés dans la revue, avec les bugs et glitch de saisie.\
Les versions suivantes sont aussi demandé.
- Fix
- Convertions/adaptations sur d'autre machines

Pour les calculatrices, décodage pour avoir l'algorithme du programe à faire.
Si le principe n'existe pas ailleurs (NDR : genre jeu des allumettes).

Le Projet fera l'objet d'un dépôt GitHub.
