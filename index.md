# Introduction

Here we are talking exclusively about these Obscure Systems that almost nobody knows about.
The idea is to be able to replenish the game libraries of these machines that are virtually non-existent.
It's also about preserving all the programs and documentation.

We encourage you to participate to the extent of your abilities to preserve the memory of these Obscure Systems.
